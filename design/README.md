# 승인 디자인 기준

사용자가 '좋아. 분석 방법은 어떻게 설정했어?'라고 답한 직전의 화면을 기준으로 한다. 크림 배경, 오렌지 입체형 스크린샷 입력, 왼쪽 분석 설정, 작은 메뉴와 버튼 구성이다.

봉패턴 및 갭·이동평균·볼린저 기준을 추가하면서 생겼던 별도 결과 섹션은 제거했다. 분석 정책 technical-v3와 상세 결과 복사는 유지한다. 결과의 실제 문장은 분석 데이터에 따라 달라지지만 화면 구조는 유지한다.

`baseline`은 기준 HTML·CSS·예시 이미지·결과 렌더러 사본과 파일 해시를 보관한다. 코드와 결과 레이아웃 변경을 `npm run check:design`으로 검사한다. 사용자 요청 없이 기준을 갱신하지 않는다. 스크린샷은 시각적 비교용이며 픽셀 자동 비교는 하지 않는다.

2026-11-05: 사용자의 명시적 요청(폰트 확대, 차트 입력 영역 확대, 과거 매수 후보 표시)에 따라 글자 크기·업로드 후 전체 너비 미리보기·확대 대화상자·과거 신호 차트를 변경했다. 크림/오렌지 색상과 업로드 전 일러스트는 유지했다. 320/390/768/1440px 결과 화면, 확대/원본 보기, 붙여넣기를 Chromium으로 확인한 뒤 HTML/CSS/결과 렌더러 기준을 갱신했다. 결과 스크린샷의 검은 이미지는 업로드 기능 검증용 합성 이미지이며 실제 분석 검증이 아니다.

같은 날 후속 수정: 사용자가 초기 화면이 그대로라고 지적하여, 업로드 후뿐 아니라 업로드 전 입력 카드도 최대 640px로 넓히고 기울기를 없앴다. 주요 설정은 16px, 소개 본문은 17px, 입력 제목은 24px로 확대했다. Chromium의 초기/결과 화면 및 모바일 너비 검증 후 CSS와 스크린샷 기준을 갱신했다.

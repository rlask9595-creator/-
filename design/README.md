# 승인 디자인 기준

사용자가 '좋아. 분석 방법은 어떻게 설정했어?'라고 답한 직전의 화면을 기준으로 한다. 크림 배경, 오렌지 입체형 스크린샷 입력, 왼쪽 분석 설정, 작은 메뉴와 버튼 구성이다.

봉패턴 및 갭·이동평균·볼린저 기준을 추가하면서 생겼던 별도 결과 섹션은 제거했다. 분석 정책 technical-v3와 상세 결과 복사는 유지한다. 결과의 실제 문장은 분석 데이터에 따라 달라지지만 화면 구조는 유지한다.

`baseline`은 기준 HTML·CSS·예시 이미지·결과 렌더러 사본과 파일 해시를 보관한다. 코드와 결과 레이아웃 변경을 `npm run check:design`으로 검사한다. 사용자 요청 없이 기준을 갱신하지 않는다. 스크린샷은 시각적 비교용이며 픽셀 자동 비교는 하지 않는다.
